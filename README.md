# cong-thong-tin-nghiep-vu
# CỔNG THÔNG TIN NGHIỆP VỤ NỘI BỘ

Cổng thông tin nghiệp vụ là trang tài liệu tra cứu trực tuyến dành cho cán bộ, nhân viên, nhằm cung cấp các quy trình chuẩn hóa và hướng dẫn vận hành hệ thống thông tin nội bộ.

## 📌 Nội dung chính
- **Quy trình xử lý sự cố:** Hướng dẫn các bước tiếp nhận, phân loại và xử lý sự cố công nghệ.
- **Hướng dẫn sử dụng:** Các tài liệu hướng dẫn thao tác trên hệ thống.
- **Tài liệu tham khảo:** Các văn bản, quy định và tài liệu kỹ thuật liên quan.

## 🛠 Nền tảng sử dụng
- **Docsify:** Trình tạo trang tài liệu tĩnh trực tiếp từ các file Markdown.
- **GitHub Pages:** Lưu trữ và triển khai trang web tự động.
